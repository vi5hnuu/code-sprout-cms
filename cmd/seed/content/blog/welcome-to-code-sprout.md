Code Sprout has been rebuilt from the ground up. It is now a place to **learn a topic, practise it, and keep track of your progress**, with every piece designed to stay fast whether we host a thousand articles or a million.

## What is new

### Articles you can run

Code in our tutorials is not just for reading. Press **Run** on any runnable example, change the input, and see the output a moment later. Many examples come in several languages. Pick yours once, and every page follows your choice.

### Problems judged in real sandboxes

Every practice problem has hidden test cases and starter code in Python, C++, Java and JavaScript. Submissions run in isolated sandboxes with real time and memory limits, the same way programming contests judge them.

### Study plans

Study plans put articles and problems in order, so you always know what to do next. Start with [DSA Essentials](/study-plans/dsa-essentials), or test yourself against the [Top Interview 10](/study-plans/top-interview-10).

### Your library

Like, bookmark and organise anything into your own lists. Your notes, submissions and an activity heatmap all live in your library.

## Write with us

Anyone can draft an article in the Studio. Read the [writing guide](/topics/writing-guide) to see what makes a great one and how review works.
