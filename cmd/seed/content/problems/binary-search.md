You are given an array of **distinct** integers sorted in increasing order and a `target`. Print the index of `target`, or `-1` if it is not in the array.

Your solution should run in O(log n) time.

## Input

- The first line holds `n`.
- The second line holds the `n` sorted integers.
- The third line holds `target`.

## Output

The 0-based index of `target`, or `-1`.

## Constraints

- `1 ≤ n ≤ 10^5`
- `-10^4 ≤ nums[i], target ≤ 10^4`
- All values are distinct and sorted in increasing order.

If you get stuck on the boundaries, read [Binary Search Without Off-by-One Errors](/dsa/binary-search).
