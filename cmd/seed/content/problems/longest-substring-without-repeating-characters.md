Given a string `s`, find the length of the longest **substring** (a contiguous run of characters) in which no character appears twice.

## Input

A single line containing `s`.

## Output

The length of the longest substring without repeating characters.

## Constraints

- `1 ≤ |s| ≤ 5·10^4`
- `s` consists of lower-case English letters and digits.

:::callout{kind=note}
A *subsequence* may skip characters; a *substring* may not. In `pwwkew` the answer is 3 (`wke`), not 4 (`pwke` is a subsequence).
:::
