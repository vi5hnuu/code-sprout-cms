Given an integer array `nums`, find the **contiguous** subarray (with at least one element) that has the largest sum, and print that sum.

## Input

- The first line holds `n`.
- The second line holds the `n` integers.

## Output

The largest possible subarray sum.

## Constraints

- `1 ≤ n ≤ 10^5`
- `-10^4 ≤ nums[i] ≤ 10^4`

:::callout{kind=tip}
The answer can be negative: when every number is negative, the best subarray is the single largest element.
:::
